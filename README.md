## HR Employee Attrition EDA

## Project Overview
This project performs Exploratory Data Analysis(EDA) on an HR Employee Attrition dataset to understand the factors associated with employee attrition.
The analysis uses Python, Pandas, Matplotlib, and Seaborn for data cleaning, exploration, and visualization.

## Objectives
- Understand the HR Employee dataset
- Identify and handle missing values
- Analyze employee attrition patterns
- Explore relationships between attrition and factors such as age, income, department, job role, and overtime
- Create meaningful visualizations
- Summarize key insights from the data

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Analysis Performed
The notebook includes:
1. Data loading and inspection
2. Data cleaning
3. Missing value analysis
4. Attrition Distribution
5. Attrition by Department
6. Salary/Income Distribution 
7. Attrition by Overtime
8. Attrition by Age
9. Key Insights

## Key Findings
The analysis shows difference in attrition based on factors such as overtime, age, income, department, and job-related characteristics.
Employees working overtime show comparatively higher attrition, while differences in average income and age can also be observed between employees who stayed and those who left.
